# **App Name**: LunchSensei

## Core Features:

- Intelligent Recommendation: Utilize a large language model tool to analyze nearby restaurants based on user's preferred taste and the restaurants star ratings, reviews, and popularity.
- History-Aware Suggestion: Incorporate user's recent meal history to avoid repetition.
- Restaurant Info Display: Provide restaurant information with key details such as address, contact number, operation hour and a link to Naver maps.
- Menu Carousel: Display the restaurant list in a scrollable view

## Style Guidelines:

- Primary color: HSL 48, 85%, 55% (RGB Hex: #F0D977). A vibrant yellow-gold to suggest appetite, energy and daylight.
- Background color: HSL 48, 20%, 95% (RGB Hex: #FAF7F0). Very light tint of the primary color, as befits a light color scheme.
- Accent color: HSL 18, 65%, 50% (RGB Hex: #E07B40). An analogous color to the primary that is slightly less bright, to indicate helpful-but-optional actions like filtering, searching, etc.
- Body and headline font: 'PT Sans' (sans-serif) for a modern yet accessible and easily readable style.
- Use clear, modern icons to represent cuisine types and dietary preferences.
- Clean, card-based layout for easy browsing and quick information access.
- Smooth transitions when switching between recommendations and restaurant details.
